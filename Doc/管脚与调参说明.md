# 管脚与调参说明

## 一、硬件管脚

| 模块 | STM32 管脚 | 说明 |
|---|---|---|
| HC-SR04 TRIG | PB14 | 前方超声波触发 |
| HC-SR04 ECHO | PB15 | 前方超声波回波；PB15 为 FT 数字输入，可选分压保护 |
| 左红外 | PA12 | 检测到障碍物为低电平 |
| 右红外 | PA11 | 检测到障碍物为低电平 |
| USART1 TX | PA9 | 接 USB-TTL 的 RX |
| USART1 RX | PA10 | 接 USB-TTL 的 TX，当前预留接收 |
| L298N IN1 | PB6 | 左电机方向控制 |
| L298N IN2 | PB7 | 左电机方向控制 |
| L298N IN3 | PB8 | 右电机方向控制 |
| L298N IN4 | PB9 | 右电机方向控制 |
| L298N ENB | PA1 / TIM2_CH2 | 右电机 PWM |
| L298N ENA | PA2 / TIM2_CH3 | 左电机 PWM |

## 二、红外电平

本工程已经设置为：检测到障碍物 = 低电平。

```c
#define IR_BLOCKED_LEVEL 0
```

代码位置：`USER/config.h`。

## 三、PWM 调节

所有 PWM 值均在 `USER/config.h` 中集中修改。本版已把差速驱动 PWM 调低：

```c
#define MOTOR_FORWARD_PWM         650
#define MOTOR_SLOW_PWM            620
#define MOTOR_TURN_LOST_PWM       560
#define MOTOR_TURN_INNER_PWM      550
#define MOTOR_TURN_OUTER_PWM      980
#define MOTOR_TURN_BACK_SPIN_PWM  650
```

本版左右 90°转弯使用低速脉冲式差速转弯，左转时右轮快、左轮慢；右转时左轮快、右轮慢。死路掉头使用一侧正转、一侧反转的分段原地左旋，前方超声波恢复到安全距离后提前退出。

## 四、转弯时间调节

```c
#define FRONT_TURN_BACK_CLEAR_CM  15
#define FRONT_RIGHT_TURN_DISTANCE_CM 18
#define MAZE_IR_CONFIRM_COUNT     2
#define MAZE_TURN_STEP_MS         45
#define MAZE_TURN_STEP_PAUSE_MS   20
#define MAZE_TURN_LOST_FORWARD_MS 200
#define MAZE_TURN_MIN_MS          260
#define MAZE_TURN_MAX_MS          1200
#define MAZE_TURN_BACK_MIN_MS     260
#define MAZE_TURN_BACK_STEP_MS    80
#define MAZE_TURN_BACK_CHECK_PAUSE_MS 20
#define MAZE_TURN_BACK_MAX_MS     1800
```

90°转弯由状态机分段执行。左转看到左侧开口就触发；右转需要右侧开口且前方距离不大于 `FRONT_RIGHT_TURN_DISTANCE_CM`，避免等到 `FRONT_SAFE_DISTANCE_CM` 才转导致太晚。达到 `MAZE_TURN_MIN_MS` 后，对应侧红外连续 `MAZE_IR_CONFIRM_COUNT` 次检测到墙就退出；如果一直没有确认，则达到 `MAZE_TURN_MAX_MS` 后兜底退出。转弯期间若左右红外都检测不到墙且前方安全，每次转弯状态最多会用 `MOTOR_TURN_LOST_PWM` 前进 `MAZE_TURN_LOST_FORWARD_MS` 做一次补位，然后继续原转弯状态。想让动作更细腻，可减小 `MAZE_TURN_STEP_MS`；转弯不足可增大 `MAZE_TURN_MAX_MS` 或略微提高 `MOTOR_TURN_OUTER_PWM`。掉头由 `MOTOR_TURN_BACK_SPIN_PWM`、`MAZE_TURN_BACK_STEP_MS` 和 `MAZE_TURN_BACK_CHECK_PAUSE_MS` 调节动作细腻程度；达到 `MAZE_TURN_BACK_MIN_MS` 后，当前方超声波距离连续大于 `FRONT_TURN_BACK_CLEAR_CM` 时提前退出，`MAZE_TURN_BACK_MAX_MS` 是最大兜底时间。

检测到需要转弯后，小车只会先停止 `MAZE_STOP_BEFORE_TURN_MS`，让车身稳定后直接进入转弯状态，不再执行转弯前前进动作。

转弯期间进入独立状态，不再执行新的路口决策。例如右侧空旷触发右转后，会持续执行右转状态；达到最小转弯时间后，只有右侧红外连续检测到墙，或达到最大转弯时间，才会回到普通左手原则决策。掉头完成后会跳过下一次左侧开口，避免立刻左转回到掉头前的来路。

## 五、算法说明

迷宫算法位于 `APP/maze.c`。

核心逻辑已改为左手原则：

```text
左侧无障碍 -> 左转
前方安全 -> 前进
右侧无障碍 -> 右转
否则 -> 分段原地左旋掉头，直到前方超声波恢复安全距离或达到最大兜底时间
```

## 六、USART1 串口状态输出

- PA9：USART1_TX，接 USB-TTL 的 RX。
- PA10：USART1_RX，接 USB-TTL 的 TX，当前预留接收。
- 串口参数：115200-8-N-1。
- 输出格式：`US=18cm,US_OK=1,IR_L=BLOCK,IR_R=CLEAR,PWM_L=+600,PWM_R=+800`。
- `US_OK=0` 表示超声波本次测距失败，车辆会停止并等待下一次检测。
- `IR_L` 和 `IR_R` 分别表示左右红外状态：`BLOCK` 为检测到障碍物，`CLEAR` 为无障碍。
- `PWM_L` 和 `PWM_R` 分别表示左右电机实际 PWM。正数为前进，负数为后退，`0` 为停止。
- 输出周期：约 0.3 s。
- 开关、波特率和输出周期在 `USER/config.h` 中调整：

```c
#define UART_STATUS_ENABLE        1
#define UART1_BAUDRATE            115200U
#define UART_STATUS_INTERVAL_MS   300U
```

注意：USB-TTL 与 STM32 必须 GND 共地。

## 七、HC-SR04 电平保护

HC-SR04 通常使用 5V 供电，其 ECHO 输出约为 5V。STM32F103 的 PB15 属于 FT（5V tolerant）数字输入，因此可以直接连接。若使用来源不明的兼容板或希望增加保护，也可以增加分压电阻或电平转换模块。
